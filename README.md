# Hospital Healthcare Data Analysis (SQL - Power BI - Slides Presentation)

This project is initiated because I feel the need to showcase my ability in SQL, Power BI, and slides presentation. I like that it is a neat and compact project. I chose hospital healthcare for this project as some sort of shout-out to pharmacy, the field of study to which I got my degree on, nothing more conclusive than that.

The sections are divided into four parts. They are:
1. Business and Data Understanding
2. Data Cleaning
3. Analysis
4. Insight and Recommendation

There are 55K+ patients in the dataset. The data can be found on Kaggle (https://www.kaggle.com/datasets/prasad22/healthcare-dataset) and specifically stated for the use of learning material. The objective is to find trend and patterns in the dataset. After defining the objectives, I cleaned the data by checking the data type suitability, relevance check, missing value check, and duplicate check. After making sure that the data is cleaned, I moved forward to analysis. All data cleaning and analysis steps are performed with SQL. 

After getting the full context of the data, I wrote my insights and recommendation. Since the data is highly synthesized, I would not recommend in using the data for learning material. This is shown by highly similarities across the data, except in some parts, for instance the correlation between age group and medical condition. Overall, the dataset could be used for general learning, but would provide less context if we want to deep dive into it. The detailed analysis is provided in the notebook and all the queries I made can be seen through the SQL file.

I moved forward by designing visualization in Power BI. There are key elements that I show, for example the main parameters (total patients, leading medical condition, and leading age group). I also added slicers for easier navigation. Trendlines and charts are also added to provide better comprehension to the audience. The visualization can be seen through the Power BI file while a detailed look on how I present the visualization can be found in the slides.
